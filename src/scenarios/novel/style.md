# 风格规范 — 小说创作

## 叙事原则
- **场景优于概述**（scene over summary）：能演给读者看的，不要总结
- **行为优于解释**（show, don't tell）："他生气了" 改为 "他把茶杯轻轻放下，指节泛白"
- **具体优于抽象**："一道光" → "斜阳在木地板上拉出一条橘色长方形"
- **节奏即呼吸**：长句铺陈，短句切断；高潮处用短句，铺垫处可舒展

## 视角
- 一旦选定视角（第一人称 / 第三人称限制 / 全知）就不要中途跳视角
- 第三人称限制视角下，叙述者只能写当下视点人物能感知的事物
- 跨场景换视角必须有清晰的分隔（章节分界、空行、明确的转场）

## 对话
- 对话承担三重任务之一：推进情节 / 揭示人物 / 暗示信息差。三个都不沾的对话删掉
- 每个主要人物有自己的语言特征：用词、句长、口头禅、回避的话题
- 善用"潜台词"：人物说 A 其实想表达 B
- 慎用对话标签：少用 "他咆哮道"/"她娇嗔道"，多用动作代替

## 描写
- 五感不要只用视觉。听觉、触觉、嗅觉的细节往往更难忘
- 环境描写要服务于情绪 / 主题 / 人物，不要纯展示
- 避免清单式描写（不要把房间从左到右扫一遍）

## 该避免的
- 过度形容词堆砌（"美丽的、动人的、令人心醉的笑容"）
- 副词替代具体动作（"他生气地说"不如"他把书一摔说"）
- 上帝视角解释人物心理（让人物的行为去暗示）
- 重复的口头禅 / 比喻 / 句式
- 信息倾倒（infodump）：世界观一次性灌给读者

## 章节结构
- 开头：用动作 / 对话 / 异常切入，不要先描写天气和环境
- 中段：每个场景有目标→冲突→结果
- 结尾：留钩子（疑问、反转、决定），让读者想翻下一章

## 标注
- 临时占位用 `<TBD: 待确认>`，便于事后搜索
- 待修订的薄弱段落用 `<WEAK: 原因>` 标注
- 伏笔与回收对应可用 `<SEED: ch3>` / `<PAYOFF: from ch3>` 注释（最终发布时删除）

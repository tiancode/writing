# 章节摘要库

> 长程一致性的关键文件。每写完一章，必须追加一条摘要。
> 写新章节前，必须 Read 至少最近 3-5 条摘要。

## 摘要格式

每章一段，按以下顺序：

```
### 第 N 章 — {章节标题}
- 时间锚点：故事内时间（如：第 3 天 / 春末 / 大战后第 7 年）
- POV：本章视点人物
- 主要场景（1-2 句）：
- 情节推进：本章推动了哪条主线 / 完成了哪个节拍
- 揭示：本章向读者揭示了什么之前不知道的信息
- 人物变化：
  - {人物 A}：
  - {人物 B}：
- 埋下伏笔：<SEED> 简述 + 计划回收章节
- 收回伏笔：<PAYOFF> 来自第 X 章的什么伏笔
- 结尾钩子：
```

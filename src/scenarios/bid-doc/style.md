# 风格规范 — 投标文档

## 语气
- 正式、克制、商业化
- 第一人称用"我方"/"投标人"，与招标文件保持一致（招标文件若用"供应商"则跟随）
- 禁用情绪化词语："非常"、"特别"、"绝对"、"百分百"

## 反"虚词"清单
以下表达全部需要替换为具体数据：

| 禁用 | 改为 |
|------|------|
| 多年经验 | 自 YYYY 年至今 N 年 |
| 实力雄厚 | 注册资本 X 万 / 员工 N 人 / 营收 Y 亿 |
| 行业领先 | 排名第 N（数据来源：XX 报告 YYYY 版） |
| 案例丰富 | 已交付 N 个同类项目（清单见附录） |
| 高性能 | TPS / QPS / 响应时间 具体数值 |
| 安全可靠 | 等保 X 级 / ISO 27001 / 故障率 < X% |

## 结构
- 应答正文必须遵循"需求理解 → 应答方案 → 案例佐证 → 交付承诺"四段式
- 评分点（评审项）必须有明显的视觉锚点：加粗 / 编号 / 颜色块（用 Markdown 表格代替）
- 长清单一律表格化（资质、案例、人员、设备）
- 每个章节首页给出"章节响应概览"小表，方便评委评分

## 案例描述格式
```
项目名称：XXX
建设单位：XXX（甲方全称）
合同金额：XXX 万元
建设周期：YYYY-MM ~ YYYY-MM
我方角色：总集成 / 分包 / 实施
关键成果：（与本次招标需求对应的关键指标）
```

## 标注
- 未确认信息一律 `<TBD: 需公司提供 XX>`，便于最终交叉检查
- 偏离项必须在章节末和总偏离表双重列出
